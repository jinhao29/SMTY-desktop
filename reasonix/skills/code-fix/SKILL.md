# Code Fix 代码修复 Skill

基于智谱 GLM 的代码缺陷修复能力。用于分析 bug、定位根因、给出最小修复。

## 能力

- ✅ 分析异常堆栈 / 报错日志，定位根因
- ✅ 审阅代码找出缺陷（空指针、越界、资源泄漏、竞态等）
- ✅ 给出最小可用的修复建议（不引入无关改动）

## 使用方式

```
code-fix --messages '[{"role": "user", "content": "这段代码报 NullPointerException，帮我定位根因：\n<粘贴代码或堆栈>"}]'
```

## 最佳实践

- 附上完整报错堆栈与相关代码片段，结果更精准
- 要求"最小改动"可避免模型输出无关重构
