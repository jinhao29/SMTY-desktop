### 3.1 数据流转：桌面端 ↔ Android 端

#### ⚠️ 严重缺口（重点痛点）

**当前实现完全无法对接 Android 端的备份文件**：

通过 Grep 全局扫描 `import sqlite3 / requests / export_meta / .db / cv2 / mediapipe`，结果**全部为 No matches found**。

`archive_manager.py` 中的 `backup_directory` 与 `restore_from_zip` 实现如下：

```python
def backup_directory(dir_path, target_zip_path):
    # 仅打包 .xlsx 文件，跳过所有其他类型
    with zipfile.ZipFile(target_zip_path, 'w', zipfile.ZIP_DEFLATED) as zf:
        for f in os.listdir(dir_path):
            if not f.lower().endswith('.xlsx'):   # ← 关键：只接受 .xlsx
                continue
            ...
            zf.write(fp, arcname=f)

def restore_from_zip(zip_path, target_dir):
    # 仅解压 .xlsx 文件
    with zipfile.ZipFile(zip_path, 'r') as zf:
        for name in zf.namelist():
            if not name.lower().endswith('.xlsx'):   # ← 关键：只接受 .xlsx
                continue
            ...
```

**对照 Android 端 BackupManager.kt**：
- Android 端 BackupManager 会生成 zip，包含 `.db`、`export_meta.json`、`签到照片.jpg`、`课时记录.xlsx`
- Python 端 `restore_from_zip` 收到该 zip 时，会**完全静默地丢弃**所有 .db / .json / .jpg 文件，仅解压 .xlsx（如果存在）

**结论**：Android 与 Python 桌面端目前是**两套完全独立的数据系统**，未实现真正打通。

## 6. 当前已知痛点与工程约束（重点）

### 6.1 ⚠️ Android ↔ Python 数据对接缺口（最严重）

**对照 Android 端 BackupManager.kt**：

Android 端生成的 zip 包含：
- `app.db`（SQLite 数据库，含 students/lessons/coaches/packages 等 7+ 张表）
- `export_meta.json`（核心列表导出元数据，含 students/lessons/packages 三个清单）
- `签到照片.jpg`（加密存储，密钥从用户私钥派生）
- `课时记录.xlsx`（兼容导出）

Python 端当前 `restore_from_zip` 实现：

```python
for name in zf.namelist():
    if not name.lower().endswith('.xlsx'):   # ← 关键过滤
        continue
```

**问题清单**：

1. **数据丢失**：Android zip 中的 `.db` / `export_meta.json` / 签到照片全部被静默丢弃
2. **路径硬编码**：仅识别 `.xlsx`，无法识别 Android 端的 sqlite 数据库
3. **无 sqlite3 引入**：Python 标准库 `sqlite3` 未被使用，无法读取 .db
4. **无照片解密**：未实现 PhotoCrypto 对应的解密逻辑
5. **路径分隔符差异**：Android zip 内路径使用 `/`，Windows 解压时未做归一化处理（`os.path.join` 在 Windows 上用 `\`，可能导致路径错位）
6. **export_meta.json 未利用**：Android 端精心设计的快速索引清单被忽略

### 6.2 ⚠️ PyInstaller .spec 严重过时

当前 .spec 的 `datas` 与 `hiddenimports` 仅包含 12 个文件，缺失约 20+ 个新模块（详见 1.3 节）。直接打包会导致 EXE 启动后崩溃或核心功能缺失。

### 6.3 ⚠️ 姿态识别模块未接线（pose_recognition 为实验残留）

`pose_recognition/` 子模块（pose_analyzer / video_processor / pose_worker / pose_screen / pose_report / opencv_jump_analyzer）**已存在于仓库**，依赖 `mediapipe` + `opencv-python`，但**从未被主程序接线**：

- 主程序（app.py / main_window / data_center 等）无任何 `import pose_recognition`
- 无对应 UI 入口 / 菜单项
- **无 YOLOv8 / ultralytics / CUDA 依赖**：全局检索 `yolo` / `ultralytics` / `onnxruntime` 零命中，该模块实际技术栈为 MediaPipe Pose，非文档早期声称的"YOLOv8-pose 双后端"

处理决策（本次审查后执行）：该模块从当前版本**裁剪**，并从 .spec 中移除 `pose_recognition` / `mediapipe` / `cv2` 相关打包项，以减小发布包体积（约数百 MB）。若未来要真正接入姿态识别，再评估技术选型。

### 6.4 文件覆盖防护机制

`excel_builder.py` 的 `append_record`：

```python
def append_record(student, dir_path):
    safe_name = student['name'].replace('/', '_').replace('\\', '_').strip()
    file_path = os.path.join(dir_path, f"{safe_name}.xlsx")
```

**防护现状**：
- 仅过滤 `/` `\` 两个字符
- **未处理** `:` `*` `?` `"` `<` `>` `|` 等 Windows 非法字符
- **未处理**重名（同名学员视为同一档案，更新而非新增）
- **未处理**前后空格、全角字符、零宽字符
- 与 Android 端「7 张表级联更新」相比，桌面端无外键约束，删除学员仅删档案不删课时记录（保留历史）

## 核心入口文件 app.py 完整代码

```python
# -*- coding: utf-8 -*-
"""统一应用入口：整合「体测档案与课时管理」+「训练任务编排」为单一窗口。

启动方式：python app.py
启动后通过顶部 Tab 切换：
  - 体测档案与课时管理（含成绩录入、档案追加、课时管理入口）
  - 训练任务编排（单次训练单 / 周计划表，导出 Excel/Word）

设计说明：
- 不改动两个现有 main.py 的内部逻辑，仅通过取出其 centralWidget 嵌入统一 Tab
- 两个子 MainWindow 实例保留为成员，确保其信号槽与状态正常工作
- 共用深色主题样式
"""
import os
import sys
import importlib.util


def _get_base_dir():
    """获取基础目录：打包后用 _MEIPASS 或 exe 目录，源码运行用源码目录。"""
    if getattr(sys, 'frozen', False):
        # PyInstaller onedir: exe 所在目录；onefile: _MEIPASS 临时解压目录
        meipass = getattr(sys, '_MEIPASS', None)
        if meipass and os.path.isdir(os.path.join(meipass, 'training_tool')):
            return meipass
        return os.path.dirname(sys.executable)
    return os.path.dirname(os.path.abspath(__file__))


HERE = _get_base_dir()
TRAINING_DIR = os.path.join(HERE, 'training_tool')
DATA_CENTER_DIR = os.path.join(HERE, 'data_center')
PROFILE_DIR = os.path.join(HERE, 'student_profile')

# 让 training_tool / data_center / student_profile 内的模块可被顶层导入
for _d in (TRAINING_DIR, DATA_CENTER_DIR, PROFILE_DIR):
    if _d not in sys.path:
        sys.path.insert(0, _d)


def _load_module(mod_name, file_path):
    """按文件路径加载模块，避免两个 main.py 同名冲突。"""
    spec = importlib.util.spec_from_file_location(mod_name, file_path)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod


# 加载体测档案主程序（当前目录 main.py）
archive_mod = _load_module('archive_main', os.path.join(HERE, 'main.py'))
# 加载训练编排主程序（training_tool/main.py）
training_mod = _load_module('training_main', os.path.join(TRAINING_DIR, 'main.py'))

from PySide6.QtWidgets import QApplication, QMainWindow, QTabWidget
from PySide6.QtGui import QFont
from theme import FINANCIAL_QSS

# 共用浅色金融风主题（全局统一）
GLOBAL_QSS = FINANCIAL_QSS


class App(QMainWindow):
    """统一主窗口：Tab 容器。"""

    def __init__(self):
        super().__init__()
        self.setWindowTitle('上门体育教学管理平台')
        # 根据屏幕可用尺寸自适应设置窗口初始大小，避免窗口高度超出屏幕导致底部不可见
        screen = QApplication.primaryScreen()
        if screen is not None:
            avail = screen.availableGeometry()
            init_w = min(1200, avail.width() - 40)
            init_h = min(860, avail.height() - 20)
            self.resize(init_w, init_h)
            # 最小尺寸保证内容基本可用，且不会超出小屏幕
            self.setMinimumSize(min(960, avail.width() - 40), min(560, avail.height() - 20))
        else:
            self.resize(1200, 860)
            self.setMinimumSize(960, 560)

        tabs = QTabWidget()
        tabs.setStyleSheet("""
            QTabWidget::pane { border: none; background: #F2F5F8; }
            QTabBar::tab {
                background: #FFFFFF;
                color: #6B7280;
                padding: 11px 30px;
                font-size: 14px;
                font-weight: 600;
                border: none;
                border-top-left-radius: 10px;
                border-top-right-radius: 10px;
                margin-right: 4px;
            }
            QTabBar::tab:hover { background: #F3F4F6; color: #4F46E5; }
            QTabBar::tab:selected {
                background: #FFFFFF;
                color: #4F46E5;
                border-bottom: 2px solid #4F46E5;
            }
        """)

        # 按教学流程重排 Tab 顺序：学员档案 → 体测档案与课时 → 训练任务编排 → 数据中心
        # 注意：archive_win 必须先创建，因为其他 Tab 依赖 archive_dir_getter 读取档案目录

        # 先创建体测档案主窗口（提供档案目录源）
        self.archive_win = archive_mod.MainWindow()
        archive_widget = self.archive_win.takeCentralWidget()

        # Tab 1：学员档案（教学流程起点：建立学员基础信息 + BMI + 续费预警）
        from profile_screen import ProfileScreen
        self.profile_screen = ProfileScreen(
            archive_dir_getter=lambda: self.archive_win.le_dir.text().strip()
        )
        tabs.addTab(self.profile_screen, '  学员档案  ')

        # Tab 2：体测档案与课时管理（测评录入 + 课时管理）
        tabs.addTab(archive_widget, '  体测档案与课时  ')

        # Tab 3：训练任务编排（基于测评制定训练计划，共用全局金融风主题）
        self.training_win = training_mod.MainWindow()
        training_widget = self.training_win.takeCentralWidget()
        tabs.addTab(training_widget, '  训练任务编排  ')

        # Tab 4：数据中心（备份 / 成长报告 / 续费预警）
        from data_center_window import DataCenterWindow
        self.data_center = DataCenterWindow()
        self.data_center.set_archive_dir(self.archive_win._dir_path)
        # 训练工具的模板库弱项推荐也需要档案目录
        self.training_win._dir_getter = self.data_center._get_dir
        tabs.addTab(self.data_center, '  数据中心  ')

        # 切换 Tab 时同步档案目录
        tabs.currentChanged.connect(self._on_tab_changed)

        self.setCentralWidget(tabs)

    def _on_tab_changed(self, idx):
        """切换 Tab 时同步档案目录到数据中心与学员档案。

        Tab 顺序（按教学流程）：
            0 学员档案 | 1 体测档案与课时 | 2 训练任务编排 | 3 数据中心
        """
        try:
            archive_dir = self.archive_win.le_dir.text().strip()
            if archive_dir:
                if archive_dir != self.data_center.le_dir.text():
                    self.data_center.set_archive_dir(archive_dir)
                # 切换到学员档案 Tab 时自动刷新
                if hasattr(self, 'profile_screen') and idx == 0:
                    self.profile_screen.refresh()
            # 切换到训练任务编排 Tab 时，刷新当前子页的学员下拉列表
            if idx == 2 and hasattr(self, 'training_win'):
                self.training_win.refresh_current_tab_students()
        except Exception:
            pass


def main():
    app = QApplication(sys.argv)
    app.setStyleSheet(GLOBAL_QSS)
    _f = QFont('Inter'); _f.setPointSize(10)
    app.setFont(_f)
    w = App()
    w.show()
    sys.exit(app.exec())


if __name__ == '__main__':
    main()
```
