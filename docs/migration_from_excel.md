# 数据迁移指南（从 Excel 导入）

场景：机构原来用 Excel 记学员名单 / 课时，迁移到本平台。

## 1. 学员名单迁移（Excel → 学员档案）

1. 数据中心 → 备份 → 「下载导入模板」，得到含表头的 Excel 模板。
2. 按模板列（姓名 / 性别 / 学校 / 联系电话）整理原 Excel 数据。
   - 姓名必填且唯一（姓名是档案主键）；
   - 其余列选填。
3. 数据中心 → 备份 → 「批量导入学员名单」，选择整理好的 Excel。
4. 已存在的同名学员会被跳过（报告中列出），不会覆盖。

## 2. 课时余额迁移（Excel → 课时汇总）

学员名单导入后，逐个学员录一次"剩余课时基数"：

- 课时管理 → 选中学员 → 修改剩余课时（录入迁移时点的真实剩余数）。
- 迁移前的历史课时明细**不必**录入：剩余课时基数已包含历史消耗。

如需保留历史明细，用「添加课时」按日期补录（日期可填过去时间），
补录明细会自动重算已上/剩余。

## 3. 从其他设备 / 旧电脑迁移

- 旧电脑：数据中心 → 一键备份所有档案（得到 zip）。
- 新电脑：安装程序 → 选择档案目录 → 从备份恢复。

## 4. 从 Android 手机端合并数据

PC 在线时手机端「立即同步」推送整库备份，PC 端自动合并（冲突逐条确认）。
详见桌面端使用指南的「双端同步」章节。

## 5. 与微信小程序互导

- 小程序「导出备份 JSON」→ 桌面端备份面板「导入小程序数据(JSON)」；
- 桌面端「导出小程序数据(JSON)」→ 微信发给教练 → 小程序「导入备份」。

## 6. 迁移核对清单

- [ ] 学员总数与原 Excel 一致
- [ ] 每位学员剩余课时与原记录一致
- [ ] 抽查 3 位学员的电话 / 年级
- [ ] 迁移完成后立即执行一次「一键备份」
