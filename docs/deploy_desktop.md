# 桌面端安装部署指南

适用：上门体育教学管理平台（桌面端，Windows）。

## 1. 环境要求

- Windows 10/11 64 位
- 无需安装 Python（发版包为 PyInstaller 冻结的可执行文件）
- 手机端连接需同一局域网（Wi-Fi）或 USB 数据线（adb）

## 2. 安装步骤（新机构从零到可用）

1. 获取安装包：GitHub Release 下载 `shangmen-tool-vX.Y.Z.zip`（附 `.sha256` 校验文件）。
2. 校验（可选）：`certutil -hashfile shangmen-tool-vX.Y.Z.zip SHA256`，与 `.sha256` 侧车文件内容一致。
3. 解压到任意可写目录（建议 `D:\shangmentiyu\`，**不要**解压到需要管理员权限的 `C:\Program Files`）。
4. 双击 `上门体育教学管理工具.exe` 启动。
5. 首次启动：
   - 在启动页选择数据模式（上门体育 / EVOLVE 俱乐部，两模式数据完全隔离）；
   - 在数据中心选择**档案目录**（学员数据全部存在这个目录，目录即数据库）。

新机构从零到可用预计 ≤ 1 小时（安装 10 分钟 + 档案目录设置 + 学员名单导入）。

## 3. 数据目录说明

| 数据 | 位置 |
|---|---|
| 学员档案 / 课时 / 收费 | 档案目录（用户自选，含 `学员档案.xlsx`、`课时记录.xlsx` 等） |
| 数据中心配置 | 档案目录下 `_data_center_config.json` |
| 运行日志 | `%USERPROFILE%\.shangmentiyu\app.log`（轮转，最大 10MB×4） |

## 4. 防火墙 / 局域网同步

- 服务随主程序自动启动（HTTP 8765 + UDP 9112 心跳广播）。
- 手机连不上时运行 `desktop_sync/firewall_allow.bat` 放行防火墙。
- USB 连接：插入手机后自动 `adb reverse`（需开启 USB 调试），手机端地址自动可用 127.0.0.1。

## 5. 升级

程序内置自动更新（GitHub Release 检查），或手动下载新 zip 解压覆盖。
档案目录数据与升级无关，升级不迁移数据。

## 6. 备份与恢复

- 一键备份：数据中心 → 备份 → 「一键备份所有档案」（zip 打包档案目录）。
- 自动备份：数据中心 → 自动备份设置（周期 + 保留份数）。
- 恢复：选择备份 zip，恢复前自动备份当前数据。

## 7. 常见部署问题

- 双击 exe 无反应：检查杀毒软件隔离记录，将解压目录加入白名单。
- 手机无法发现 PC：确认同一网段、运行 `firewall_allow.bat`、PC 端服务为"运行中"。
- 其余见 [FAQ](faq.md)。
