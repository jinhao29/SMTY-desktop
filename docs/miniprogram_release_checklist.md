## 0. 先决策：你到底要哪种体验？

小程序有**两套数据源**，默认是本地模式（`src/api/index.js:22` `authMode` 默认 `'local'`）：

| 方案 | 朋友体验到的 | 需要公网后端？ | 需要备案？ | 成本 |
|---|---|---|---|---|
| **A. 本地模式体验** | 完整 UI + 完整业务功能，数据存朋友自己手机 | ❌ 不需要 | ❌ 不需要 | **0 元** |
| **B. 连服务器体验** | 同上，但数据在你这边的服务器，多端共享 | ✅ 需要 | ✅ 需要 | 几十元/月起 + 1-3 周备案 |

**如果只是让朋友看看功能长什么样、试用一下交互 → 走 A，今天就能发。**
**如果要让朋友的数据跟你桌面端打通、多人共用一份数据 → 走 B，最快也要 1-3 周（备案）。**

## 1. 方案 A：纯本地模式体验版（推荐先做）

### 1.1 前置：正式 AppId（必须，免费）

1. 访问 https://mp.weixin.qq.com → 注册 → 选「小程序」
2. 主体类型选 **个人**，用你的身份证 + 微信实名
3. 注册完在「设置 → 基本设置」里找到 **AppID**
4. 个人主体小程序**无需**微信认证（300 元那笔是给企业/组织主体的，个人不需要）

### 1.2 替换 AppId（我来做，你给我 AppId 即可）

改两个地方：
- `miniprogram/src/manifest.json` → `mp-weixin.appid`
- 重新构建后 `dist/build/mp-weixin/project.config.json` 会自动带出

### 1.3 构建 + 上传

```bash
cd miniprogram
npx uni build -p mp-weixin
# 然后微信开发者工具打开 miniprogram/dist/build/mp-weixin 目录
# 工具栏 → 上传 → 版本号 1.0.0 / 备注「首个体验版」
```

### 1.4 设为体验版 + 加体验成员

1. mp.weixin.qq.com → 管理 → 版本管理 → 开发版本 → **设为体验版**
2. 管理 → 成员管理 → 体验成员 → 添加朋友微信号（个人主体最多 15 个体验成员）
3. 版本管理 → 体验版 → **下载二维码** → 发给朋友

### 1.5 朋友侧注意事项

- 朋友扫码后**点「跳过登录，进入本地模式」**（登录按钮走服务器，本地无后端会失败）
- 本地模式数据存朋友手机，卸载/清缓存会丢

## 2. 方案 B：接公网后端（数据打通）

### 2.1 硬门槛（这两条绕不开）

**① 域名必须 ICP 备案**
- 微信官方文档明确：「域名必须经过 ICP 备案」
- 个人主体可备案（身份证 + 手机号 + 应急联系电话）
- 周期 **1-3 周**（各省管局不同），且新备案域名需 **24-48 小时**同步到微信审核系统
- 域名持有者信息必须与备案主体**完全一致**（都是你本人）

**② 必须 HTTPS**
- Let's Encrypt 免费 DV 证书即可，微信认可，90 天有效期，**必须配自动续期**

### 2.2 部署方式选择

| 方案 | 免备案？ | 个人能开？ | 适合 |
|---|---|---|---|
| **云托管（callContainer）** | ✅ 官方免域名免备案 | ⚠️ **需先确认**（见下） | 最省事，但需改代码 |
| 云服务器 + 域名 | ❌ 要备案 | ✅ | 通用，代码不用改 |
| 内网穿透（ngrok/frp/cpolar） | ❌ 微信只认已备案域名 | — | **仅本机调试用，发不了体验版** |

> ⚠️ **云托管有争议点**：社区里出现「非个人类型小程序没有通过微信认证不能开通云服务」的错误码，
> 但同时有「个人小程序暂无微信认证限制」的说法，且有个人号实测成功的案例（认证费显示 30 元）。
> **这个必须你在开发者工具里点一下「开通云托管」才知道结果**——我无法代你验证。
> 若报 -601055，则云托管不可用，只能走备案路线。

### 2.3 云托管部署要点（若可用）

- 需要 `Dockerfile`（当前仓库**没有**，要新建）
- 必须监听云托管注入的 `PORT` 环境变量，不是固定 8800
- **容器不支持持久化存储** → 当前后端的 SQLite 文件会随扩缩容丢失，
  必须改用云托管 MySQL 或对象存储（**这是改造量最大的地方**）
- 前端要把 `uni.request` 改成 `wx.cloud.callContainer`（跨端需条件编译）

### 2.4 云服务器部署要点（备案路线）

1. 买轻量服务器（腾讯云 Lighthouse / 阿里云，国内节点，**购 3 个月以上才能备案**）
2. 后端启动加 `MP_HOST=0.0.0.0`（当前默认 `127.0.0.1`，见 `server/main.py:44`）
3. Nginx 反代 + Let's Encrypt 证书
4. 小程序后台 → 开发管理 → 开发设置 → 服务器域名 → request 合法域名 填 `https://你的域名`
5. 下载校验文件放服务器根目录完成所有权验证
6. ⚠️ 域名**不能带端口**，`https://x.com:8080` 无效

### 2.5 前端配置（我已改好，你只需填一行）

`.env.production`：
```
VITE_API_BASE_URL=https://你的域名
```
然后 `npx uni build -p mp-weixin`。

> 也支持运行时覆盖：小程序「设置 → 服务器地址」可直接改，**换服务器不用重新上传代码**。

## 5. 常见坑

1. 后端监听 `127.0.0.1` → 公网访问不到（本项目默认就是，记得设 `MP_HOST=0.0.0.0`）
2. 域名未备案 → 微信后台**无法添加**，直接报错
3. 用 HTTP → 微信拒绝请求
4. 域名带端口 → 无效
5. 开发时忘勾「不校验合法域名」→ 请求失败（但**正式上传前必须取消勾选**）
6. MP_SECRET 换了值 → 已签发 token 全部失效
7. 云托管容器无持久化 → SQLite 数据会丢，必须换 MySQL
