# 常见问题 FAQ 与远程排查

## 安装与启动

**Q：双击 exe 无反应 / 被杀毒软件删除？**
A：把解压目录加入杀毒白名单后重试。程序不写注册表、不写系统目录，卸载只需删文件夹。

**Q：升级后数据会丢吗？**
A：不会。学员数据全部在「档案目录」，与程序目录无关；升级只替换程序文件。

## 学员与课时

**Q：同名学员怎么办？**
A：姓名是档案主键，建议用"张三(2)"或加班级后缀区分。

**Q：剩余课时显示不对？**
A：课时管理 → 修改该学员剩余课时基数。明细记录的"已上"会自动重算，剩余=基数-已上。

**Q：课时预警什么时候出现？**
A：剩余 ≤3 次或课时包 30 天内到期。

## 双端同步

**Q：手机发现不了 PC？**
A：依次检查：① 同一 Wi-Fi 网段；② PC 状态显示"服务运行中"；③ 运行
`desktop_sync/firewall_allow.bat` 放行防火墙；④ 路由器开了 AP 隔离的换到同一子网。
仍不行用 USB 线（自动 adb reverse）。

**Q：同步会覆盖谁的数据？**
A：整库备份按"较新覆盖较旧"合并，冲突条目 PC 端逐条弹窗确认；恢复备份则以备份为准。

**Q：为什么要配对码？不配对能用吗？**
A：不配对可以正常自动发现与同步（兼容模式）。配对后 PC 心跳带 HMAC-SHA256 签名，
防止同网段恶意设备伪造"PC 在线"劫持手机的上传目标。建议在公共 Wi-Fi 环境的机构配对。

**Q：换了路由器 / PC 换了 IP，手机连不上？**
A：手机端设置 → 桌面同步 → 「自动发现 PC」重新点一次即可（心跳 3 秒一广播）。

## 备份与恢复

**Q：备份加密口令忘了？**
A：加密备份无法解密（无后门）。只能从最近一次未加密备份恢复。口令务必与密码管理器双备份。

**Q：自动备份存在哪里？删了会怎样？**
A：固定备份文件夹（推荐 Download）或应用目录 AutoBackups/，滚动保留最近 5 份。

## 小程序

**Q：小程序数据怎么到 PC？**
A：小程序 → 我的 → 数据 → 导出备份 → 微信/QQ 发到电脑 → PC 备份面板「导入小程序数据(JSON)」。

**Q：导入提示"模式不匹配"？**
A：小程序导出文件带有数据模式（上门/俱乐部），需在对应模式下的小程序中导入；
PC 端导出时按当前模式生成，同样需对应。

## 远程排查（联系支持前先做）

1. 桌面端：数据中心 → 备份 → 「打开日志文件夹」，把 `app.log` 发给支持人员。
2. 手机端：开启 USB 调试连电脑，执行 `adb logcat -d > phone_log.txt` 导出日志。
3. 准备好：操作时间点、档案目录路径、报错截图。
