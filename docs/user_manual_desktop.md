# 管理端使用指南（桌面端）

适用角色：机构管理者 / 前台（管理学员档案、课时、财务、数据）。
教练日常记成绩用手机端（Android），见手机端快速上手。

## 1. 启动与模式选择

- 启动后选择数据模式：**上门体育** / **EVOLVE 俱乐部**。两模式数据完全隔离
  （独立数据库与档案目录）。
- 新增机构场景：编辑 `student_sports_tool/config/modes.json`，复制一个 mode 节点，
  改 `id / display_name / db_name / archive_dir / window_title` 即可新增一个隔离数据空间，
  无需改代码。改完重启程序生效；`version` 需 +1。
- 误选模式退出重进即可切换。

## 2. 学员档案（数据中心 → 学员档案）

- 新建：姓名必填；身高体重录入后自动计算 BMI 与体型。
- 扩展字段（父/母身高、睡眠、营养评分、周运动）用于身高预测，选填。
- 学员停用（毕业/退费）：软删除，历史课时保留，可恢复。

## 3. 课时管理

- 添加课时：学员 + 日期 + 课时数；剩余课时自动扣减。
- 修改剩余课时基数：右键学员 → 修改剩余（用于迁移或手工校正）。
- 课时不足 / 到期在首页与学员列表有黄色预警（剩余 ≤3 次）。

## 4. 收费记账（收费管理）

- 录入：日期 / 学员 / 金额 / 课时数 / 收款方式。
- 课时包购买金额与上课消耗在财务页自动汇总。

## 5. 双端同步（PC ↔ 手机）

1. PC 服务随程序自动启动（端口 8765，心跳广播 UDP 9112）。
2. 手机同一 Wi-Fi 打开 App → 设置 → 桌面同步 → 「自动发现 PC」一键填地址。
3. 数据中心 → 双端同步面板 → 「信任」自己的手机。
4. 「立即同步」双向对齐；PC 改完数据会广播，手机自动拉取。
5. **安全配对（推荐）**：同步面板「生成 / 重新配对」得到配对码 →
   手机端设置 → 桌面同步 → 「配对码」粘贴。配对后 PC 心跳带 HMAC 签名，
   同网段伪造心跳无法把手机的照片上传劫持到别的机器。
6. USB 连接：手机插 USB 开调试，自动 `adb reverse`，无需 IP。

## 6. 数据中心（备份 / 导入 / 导出）

- 一键备份 / 自动备份 / 恢复（恢复前自动再备份一次）。
- 批量导入学员名单（Excel，见数据迁移指南）。
- 导出小程序数据(JSON) / 导入小程序数据(JSON)：与微信小程序互导。
- 打开日志文件夹：远程排查时把 `app.log` 发给支持人员。

## 7. 快捷键与日常习惯建议

- 每天下课铃后：手机点签到 → PC 自动收到课时记录（自动同步开启时）。
- 每周：看一次首页课时预警；每月：执行一次「一键备份」并异地保存。
